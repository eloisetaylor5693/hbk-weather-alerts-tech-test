# Weather alerts website

## Requirements

Create a React application to display alerts from the National Weather Service API in a table format

https://www.weather.gov/documentation/services-web-api#/

Consider what information a user would find valuable to see in this table. The user should be able to sort and filter the alerts in the table. Dates should be displayed in the user’s local time zone. Provide a view of a weather alert chosen from the table to display additional details about the alert. User can specify the date range of alerts they wish to view in the table.

Components should be consistently styled.

Think about the user experience, how information is presented and how the user navigates the application. There are no wrong answers, we would like to see how you approach a problem and how you work.

## Development Process

The application should be built with TypeScript and modern component libraries. You should develop this as though it were commercial software.

You may use any modern IDE of your choice, however we encourage the use of JetBrains WebStorm as it is the IDE the ReliaSoft Cloud team uses for all React development work.

Use GitHub for your source control, and submit a link to the repository when complete.

## Documentation

Code should be self-documenting, and any other documentation you wish to provide should be included in the ReadMe file in the repository.
